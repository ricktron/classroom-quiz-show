# Media fixtures

This directory holds **CI and local same-origin test assets** for the Slice 11
media contract.

- `slice-11-clue.png` — a tiny deterministic PNG used by unit and Playwright
  tests to exercise image prompts under `same-origin-path`.

These files are **not** a content pack, a classroom media library, or a
redistributable asset collection. Do not treat them as curriculum media.
