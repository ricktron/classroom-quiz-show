# Media fixtures

This directory holds **CI and local same-origin test assets** for media
contracts and Display visual stress.

- `slice-11-clue.png` — a tiny deterministic PNG used by Slice 11 unit and
  Playwright plumbing tests to exercise image prompts under `same-origin-path`.
- `s05-f1-stress-diagram.png` — a 960×540 same-origin diagram used by the
  S05-F1 / S06 visual stress fixture so projector media balance can be
  asserted (non-zero natural dimensions, useful on-screen size).

These files are **not** a content pack, a classroom media library, or a
redistributable asset collection. Do not treat them as curriculum media.
